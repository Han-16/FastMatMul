\section{Security Analysis}
\label{sec:security}

We prove that \(\protocol\) is sound for the committed matrix multiplication
statement defined in Section~\ref{sec:construction}.  The public roots
\(\rt_{ABC}\) and \(\rt_{XYZ}\) bind, respectively, to the packed encoded
matrix columns and the packed encoded symbols of the intermediate vectors.
The sampled-opening backend of Definition~\ref{def:codecom-backend} links the
sampled witnesses used by the SNARK to the corresponding opened Pedersen leaves.
Completeness and soundness are stated in Theorem~\ref{thm:security}; knowledge
soundness is discussed separately in Remark~\ref{rem:aok}.

\paragraph{Scope of the security claim}
The theorem is a statement-soundness result for committed matrix
multiplication.  It does not, by itself, claim a standalone argument of
knowledge or zero knowledge for the entire input-commitment layer.  The
committed objects are:
\[
  \rt_{ABC}
  \quad\text{and}\quad
  \rt_{XYZ},
\]
where \(\rt_{ABC}\) fixes the encoded matrix-column blocks
\(\{\vect{m}_{ABC,j}\}_{j\in[n]}\), and \(\rt_{XYZ}\) fixes the encoded
intermediate-vector blocks \(\{\vect{m}_{XYZ,j}\}_{j\in[n]}\).  The SNARK-side
commitments \(\widetilde{\cm}_{ABC}\) and \(\widetilde{\cm}_{XYZ}\) bind the
sampled blocks used inside the SNARK.  CP-Link then links these sampled blocks
to the Pedersen leaves opened under \(\rt_{ABC}\) and \(\rt_{XYZ}\).

\paragraph{Soundness-critical ordering}
The proof relies on the transcript order enforced by the construction.
First, \(\rt_{ABC}\) is fixed before the Freivalds scalar \(r\) is derived.
Thus the encoded matrices are fixed before the prover sees the challenge used
to define \(\vect{x}=\vect{r}\mat{A}\),
\(\vect{y}=\vect{x}\mat{B}\), and \(\vect{z}=\vect{r}\mat{C}\).
Second, \(\rt_{XYZ}\) is fixed before the query tuple
\(I=(j_1,\ldots,j_t)\) is derived.  Thus the encoded intermediate-vector
symbols are fixed before the sampled positions are known.  Third, the verifier
accepts sampled values only when the SNARK proof, Merkle openings, and CP-Link
proofs all accept.  Conditioned on the soundness of these components, the
values used in the sampled fold checks are exactly the values fixed by
\(\rt_{ABC}\) and \(\rt_{XYZ}\) at the queried positions.

\paragraph{Backend failure event}
The backend bad event captures the only composition point specific to our
construction.  After the transcript prefix fixes
\[
  (\rt_{ABC}, r, \rt_{XYZ}, I),
\]
the adversary outputs a SNARK proof, sampled Merkle openings, and CP-Link
proofs for the two sampled block families.  A backend failure occurs if all
these checks accept while either \(\widetilde{\cm}_{ABC}\) is not linked to the
opened blocks \((\cm_{ABC,j})_{j\in I}\), or
\(\widetilde{\cm}_{XYZ}\) is not linked to the opened blocks
\((\cm_{XYZ,j})_{j\in I}\), or an opened Merkle leaf is not the value fixed at
the claimed position under its root.  Definition~\ref{def:codecom-backend}
charges this event to \(\epsilon_{\mathsf{open}}+\epsilon_{\mathsf{link}}\),
where \(\epsilon_{\mathsf{open}}\) covers Merkle position binding and Pedersen
binding, and \(\epsilon_{\mathsf{link}}\) covers CP-Link soundness.

\begin{theorem}[Security]\label{thm:security}
The protocol \(\protocol\) satisfies the following properties.
\begin{enumerate}[label=(\roman*)]
  \item \textbf{Perfect completeness.} If
  \(\mat{A}\mat{B}=\mat{C}\), an honest prover makes the verifier accept.

  \item \textbf{Interactive computational soundness.}
  For any \(\ppt\) adversary \(\mathcal{P}^*\), let \(\mathsf{Acc}\) be the
  event that the verifier accepts a false committed matrix multiplication
  statement.  Then
\[
\begin{aligned}
\Pr[\mathsf{Acc}\mid \mat{A}\mat{B}\neq\mat{C}]
&\le
\epsilon_{\mathsf{SNARK}}(\lambda)
+\epsilon_{\mathsf{open}}(\lambda)
+\epsilon_{\mathsf{link}}(\lambda) \\
&\quad
+ \frac{k-1}{|\mathbb{F}|}
+4(1-\delta)^t .
\end{aligned}
\]
Here \(t=|I|\) is the number of sampled positions and \(\delta\) is the
relative distance of the code \(\mathcal{C}\).  The term
\(\epsilon_{\mathsf{SNARK}}\) is the soundness error of the CP-SNARK relation,
\(\epsilon_{\mathsf{open}}\) is the binding error of the Merkle/Pedersen
opening layer, and \(\epsilon_{\mathsf{link}}\) is the soundness error of the
two blockwise CP-Link checks.

  \item \textbf{Fiat--Shamir soundness.} In the random oracle model, the
  non-interactive protocol in Section~\ref{sec:protocol-desc} satisfies the
  same bound with an additional Fiat--Shamir loss
  \(\epsilon_{\mathsf{FS}}(q_H)\), where \(q_H\) is the adversary's number of
  random-oracle queries.
\end{enumerate}
\end{theorem}

\begin{corollary}[Evaluated backend]\label{cor:evaluated-backend}
For the backend used in the artifact, the opening and linking contribution in
Theorem~\ref{thm:security} can be written as
\[
  \epsilon_{\mathsf{open}}+\epsilon_{\mathsf{link}}
  \le
  \epsilon_{\mathsf{merkle}}
  +\epsilon_{\mathsf{ped}}
  +\epsilon_{\mathsf{QA}}
  +\frac{2t}{|\mathbb{F}|}.
\]
The first two terms cover Merkle position binding and Pedersen binding.  The
last two terms cover the batched CP-Link proof for the two sampled block
families, \(ABC\) and \(XYZ\).
\end{corollary}

The reported scaling rows use \(t=128\).  If \(\delta=1/2\), the proximity
term is \(4(1-\delta)^t=2^{-126}\).  A deployment that targets a different
security level can increase \(t\), choose a larger-distance code, or instantiate
the backend with smaller component errors.

\paragraph{Proof sketch}
Completeness follows from linearity of the Freivalds reduction and of the
encoding.  Honest commitments, openings, and CP-Link proofs make every sampled
fold and equality check accept.

For soundness, condition away SNARK, opening, and CP-Link failures.  Then
\(\rt_{ABC}\) fixes the encoded matrices before \(r\), and \(\rt_{XYZ}\) fixes
the encoded intermediate-vector symbols before \(I\).  The sampled values used
inside the SNARK are the same values opened from these roots.  If
\(\mat{A}\mat{B}\neq\mat{C}\), the structured Freivalds check fails to detect
the false product with probability at most \((k-1)/|\mathbb{F}|\).  Conditioned
on not hitting this Freivalds failure event, at least one of the local encoded
relations checked in Section~\ref{sec:snark-relation} is false.  By the
relative distance \(\delta\), a random sampled position misses the disagreement
with probability at most \(1-\delta\).  Union-bounding over the four checked
relations gives the \(4(1-\delta)^t\) term.  Adding the SNARK, opening,
linking, and Fiat--Shamir failure events gives the stated bound.

\begin{remark}[Fiat--Shamir soundness]\label{rem:fs-soundness}
The theorem is stated first for the public-coin interactive protocol.  The
non-interactive protocol derives \(r\), \(I\), and backend batch challenges
from domain-separated hashes of the transcript.  In the random oracle model,
the same argument applies with the standard Fiat--Shamir loss
\(\epsilon_{\mathsf{FS}}(q_H)\).
\end{remark}

\begin{remark}[Knowledge Soundness]\label{rem:aok}
The theorem above is a statement-soundness claim relative to the committed
roots \(\rt_{ABC}\) and \(\rt_{XYZ}\).  A full argument of knowledge can be
obtained by composing \(\protocol\) with an extractable commitment interface
and a knowledge-sound CP-SNARK.  This is an orthogonal composition issue; the
main theorem focuses on soundness of the matrix-multiplication checking
protocol.
\end{remark}
