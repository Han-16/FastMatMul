Efficiently proving large-scale matrix multiplication statements is one of the central bottlenecks in verifiable computation systems. A na\"ive arithmetization of \(k \times k\) matrix multiplication inside a SNARK circuit requires \(\mathcal{O}(k^3)\) constraints, while even Freivalds' randomized checking technique still incurs \(\mathcal{O}(k^2)\) circuit work. In this paper, we propose \(\protocol\), a protocol designed to reduce this circuit cost.

\(\protocol\) combines Freivalds' randomized check with a proximity test based on codeword encoding, allowing matrix multiplication statements to be verified without directly arithmetizing the entire \(k \times k\) computation inside the SNARK circuit. Concretely, instead of taking the full matrices as witnesses, the SNARK circuit receives only a small number of sampled codeword positions as witnesses and performs the proximity test on those positions. Moreover, by using Merkle openings and CP-links, \(\protocol\) ensures that the witnesses used inside the circuit correspond to the same values that were committed to before the SNARK proof was generated.

As a result, \(\protocol\) reduces the size of the SNARK relation to \(\mathcal{O}(tk)\) constraints and requires only an additional \(\mathcal{O}(t \log n) + E_{\mathsf{link}}(k)\) cost for opening and linking. Here, \(t\) denotes the number of sampled codeword positions, which is a constant independent of the matrix dimension \(k\). Thus, \(\protocol\) proves matrix multiplication using only a linear number of constraints in the matrix size. We implement \(\protocol\) in Go and compare it against a Freivalds-based SNARK circuit. For \(k=4096\), \(\protocol\) reduces the constraint count by \(30.3\times\) and shortens proof generation time by \(7.24\times\). Moreover, the verification time remains constant regardless of the matrix size, taking less than \(0.01\) seconds.
