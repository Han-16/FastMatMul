\section{Security Analysis}
\label{sec:security}

We prove that the protocol $\protocol$ (Figure~\ref{fig:protocol}) constitutes a secure interactive argument for the matrix multiplication relation $\mathcal{R}_{\mathsf{orig}}$ relative to a code-commitment backend and certified encoded input commitments.
Soundness and completeness are established in Theorem~\ref{thm:security} below; knowledge soundness is discussed separately in Remark~\ref{rem:aok}.
As discussed in Section~\ref{sec:relation-chain}, the public input commitments $\cm_A,\cm_B,\cm_C$ are assumed to bind to row-wise encodings of fixed matrices $\mat{A},\mat{B},\mat{C}$.
This is the committed-input model used by code-based proof systems such as Brakedown~\cite{golovnev2023brakedown} and Orion~\cite{xie2022orion}; $\protocol$ verifies the multiplication relation among these committed objects.
For the intermediate vectors, the SNARK relation invokes the selected
code-commitment backend relation $\codeComV(\cm_v,v,\sigma_v)$, ensuring that the commitments
$\cm_x,\cm_y,\cm_z$ bind to full codewords $\enc(\vect{x}),\enc(\vect{y}),\enc(\vect{z})$
before the query tuple is sampled.
In the QA-linked implementation, this relation is realized by pre-query
commitments to the intermediate message vectors, in-circuit Reed--Solomon
encoding checks, Merkle membership for sampled leaves, and CP-linking between
the circuit-internal sampled values and the externally committed leaves.
The theorem therefore does not assert soundness for arbitrary Merkle roots
alone: without certified inputs and pre-query binding of the intermediate
vectors, sampled local checks can be made consistent without representing a
valid encoded vector.

\paragraph{Soundness-critical ordering}
The proof uses the following timing invariants.
First, the certified input roots $\cm_A,\cm_B,\cm_C$ are fixed before the
Freivalds challenge $r$ is sampled.
Second, the intermediate roots $\cm_x,\cm_y,\cm_z$ are fixed before the query
tuple $I=(j_1,\ldots,j_t) \sample [n]^t$ is sampled; conditioned on an
accepting backend proof, each such root is globally linked to one full vector
codeword independently of the sampled positions.  In the QA-linked
instantiation, the transcript first fixes the intermediate message commitments
and encoded-view roots, and only then derives $I$; the accepted CP-link proofs
then identify every opened sampled leaf with the corresponding in-circuit
coordinate of $\enc(v)$.
Third, the entries of $I$ are sampled independently with replacement, as
defined in Section~\ref{sec:notation}.
If an implementation samples without replacement, the proximity failure
probability only decreases; the theorem states the simpler with-replacement
bound.

\begin{theorem}[Security]\label{thm:security}
The protocol $\protocol$ satisfies the following properties:
\begin{enumerate}[label=(\roman*)]
  \item \textbf{Perfect completeness.} If $\mat{A}\mat{B} = \mat{C}$, an honest prover always makes the verifier accept.
  \item \textbf{Interactive computational soundness.}
  For any $\ppt$ adversary $\mathcal{P}^*$ given certified public input
  commitments to $\mat{A},\mat{B},\mat{C}$, let $\mathsf{Acc}$ be the event
  that the verifier accepts a false committed matrix statement.
  Then:
\[
\begin{aligned}
\Pr[\mathsf{Acc} \mid \mat{A}\mat{B} \neq \mat{C}]
&\le
\epsilon_{\mathsf{SNARK}}(\lambda)
+ \epsilon_{\mathsf{cc}}(\lambda)
+ \epsilon_{\mathsf{bind}}(\lambda) \\
&\quad + \frac{k-1}{|\mathbb{F}|}
+ 4(1 - \delta)^{t},
\end{aligned}
\]
Here $t = |I|$ is the query complexity and $\delta$ is the relative minimum
distance of $\mathcal{C}$.
The terms $\epsilon_{\mathsf{SNARK}}$, $\epsilon_{\mathsf{cc}}$, and
$\epsilon_{\mathsf{bind}}$ denote, respectively, the soundness error of the
SNARK backend, the codeword-binding error of the selected code-commitment
backend (including message-commitment and CP-link failures in the QA-linked
instantiation), and the union-bounded position-binding error of the opening
layer over all roots and openings used in the protocol.
  \item \textbf{Fiat--Shamir soundness.} In the random oracle model, the
  non-interactive variant described in Section~\ref{sec:protocol-desc}
  satisfies the same bound with an additional Fiat--Shamir loss term
  $\epsilon_{\mathsf{FS}}(q_H)$, where $q_H$ is the adversary's number of
  random-oracle queries.
\end{enumerate}
\end{theorem}

\begin{proof}[Proof sketch]
Completeness is immediate from linearity: if $\mat{A}\mat{B}=\mat{C}$, then
for every Freivalds challenge $\vect{r}$ the honest vectors satisfy
$\vect{x}=\vect{r}\mat{A}$, $\vect{y}=\vect{x}\mat{B}$,
$\vect{z}=\vect{r}\mat{C}$, and hence $\vect{y}=\vect{z}$.
Linearity of the code makes every sampled fold identity hold, and the honest
commitment/opening proofs verify.

For soundness, condition on the complement of three backend failures:
SNARK soundness, codeword binding for the intermediate roots, and
position-binding for accepted openings.
These contribute
$\epsilon_{\mathsf{SNARK}}(\lambda)+\epsilon_{\mathsf{cc}}(\lambda)+
\epsilon_{\mathsf{bind}}(\lambda)$.
Under this conditioning, the certified input roots determine fixed matrices
before $r$ is sampled, and each accepting intermediate commitment determines
the vector and encoded coordinates used by the circuit before the sampled query
tuple $I$ is sampled.  For the QA-linked backend, this means the message
commitments and encoded-view roots are fixed before $I$, and every opened
sampled coordinate is CP-linked to the corresponding in-circuit coordinate of
$\enc(v)$.
If $\mat{A}\mat{B}\neq\mat{C}$, then for
$\mat{D}=\mat{A}\mat{B}-\mat{C}\neq 0$ the equation
$\vect{r}\mat{D}=0$ is a nonzero univariate polynomial test of degree at most
$k-1$, so Schwartz--Zippel bounds the Freivalds failure by
$(k-1)/|\mathbb{F}|$.
Conditioned further on $\vect{r}\mat{D}\neq 0$, no vectors can satisfy all four
global equalities $\vect{x}=\vect{r}\mat{A}$,
$\vect{y}=\vect{x}\mat{B}$, $\vect{z}=\vect{r}\mat{C}$, and
$\vect{y}=\vect{z}$.
At least one corresponding pair of codewords is therefore distinct, and the
relative distance $\delta$ makes a random queried coordinate reject with
probability at least $\delta$.
Taking $t$ independent sampled coordinates and union-bounding over the four
relations gives $4(1-\delta)^t$.
The Fiat--Shamir statement follows by the standard random-oracle loss for the
transcript-derived challenge and query tuple.
Appendix~\ref{app:security-proof} gives the detailed proof.
\end{proof}

\begin{remark}[Fiat--Shamir soundness]\label{rem:fs-soundness}
The proof of the main bound in Theorem~\ref{thm:security} is for the
public-coin interactive protocol.
The non-interactive variant in Section~\ref{sec:protocol-desc} derives both
$r$ and $I$ from domain-separated hashes of the full transcript prefix.
In the random oracle model, the same proof applies with the standard
Fiat--Shamir loss $\epsilon_{\mathsf{FS}}(q_H)$, where $q_H$ is the adversary's
number of random-oracle queries.
This term accounts for grinding over transcript prefixes and is negligible for
polynomial $q_H$ when the challenge and query hashes have $\lambda$-bit
security.
\end{remark}

\begin{remark}[Knowledge Soundness]\label{rem:aok}
The theorem above is a statement-soundness result relative to certified public input commitments.
A full \emph{argument of knowledge} can be obtained by composing $\protocol$ with an extractable input-commitment interface and a knowledge-sound SNARK.
In that setting, the input-commitment extractor yields openings of $\cm_A,\cm_B,\cm_C$ to row-wise encoded matrices, while the SNARK extractor yields the intermediate vectors and queried openings used in $\mathcal{R}_{\mathsf{SNARK}}$.
The same soundness argument then implies that any prover accepted with non-negligible probability is bound, except with the stated error, to matrices satisfying $\mat{A}\mat{B}=\mat{C}$.
We treat this as an orthogonal composition issue and focus the main theorem on the multiplication-checking protocol.
\end{remark}
