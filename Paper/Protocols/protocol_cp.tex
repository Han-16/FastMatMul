Let $I \subset [n]$ be the set of queried indices. We denote the set of intermediate matrices as $\mathcal{M} = \{\mat{A}, \mat{B}, \mat{C}\}$ and the set of vectors as $\mathcal{V} = \{\vect{x}, \vect{y}, \vect{z}\}$. The core algebraic relation $\mathcal{R}_{\mathsf{base}}$, which is evaluated inside the decoupled CP-SNARK circuit, is formally defined as follows:
\[
\mathcal{R}_{\mathsf{base}} = \left\{
\left( 
\begin{array}{l}
\stmt = \Big( \{ \enc_{v}^{(j)} \}_{j \in I, v \in \mathcal{V}}, r, I \Big) ; 
\\
\wit = \Big( \{ v \}_{v \in \mathcal{V}},  \{ \enc_{M}^{(j)} \}_{j \in I, M \in \mathcal{M}} \Big)
\end{array}
\right)
\ \middle\vert \
\begin{array}{l}
\bigwedge_{v \in \mathcal{V}} \Big( \enc_v = \enc(v) \Big) 
\\
\bigwedge_{j \in I} \left( \enc_x^{(j)} = \fold(\enc_A^{(j)},\vect{r}) \right) 
\\
\bigwedge_{j \in I} \left( \enc_y^{(j)} = \fold(\enc_B^{(j)},\vect{x}) \right)
\\
\bigwedge_{j \in I} \left( \enc_z^{(j)} = \fold(\enc_C^{(j)},\vect{r}) \right)
\\
\bigwedge_{j \in I} \Big( \enc_y^{(j)} = \enc_z^{(j)} \Big)
\end{array}
\right\}
\]
